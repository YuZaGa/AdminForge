# AdminForge Documentation

AdminForge is a Django-like admin panel for Next.js with built-in AI agent orchestration. Define your schema in `adminforge.ts`, run a few commands, and get a fully functional admin dashboard with REST API, RBAC, and MCP-based AI agent support.
